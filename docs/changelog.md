# Changelog

Release notes for every Dawarich version, including upgrade steps for self-hosted instances, are published with each [GitHub release](https://github.com/Freika/dawarich/releases). The full history is in [CHANGELOG.md](https://github.com/Freika/dawarich/blob/master/CHANGELOG.md).

For an overview of recent releases and what is coming next, see the [roadmap](/roadmap).
