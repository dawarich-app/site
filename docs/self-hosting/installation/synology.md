# Synology

For installation on a Synology NAS, follow [How to Install Dawarich on Your Synology NAS](https://mariushosting.com/how-to-install-dawarich-on-your-synology-nas/) by Marius Hosting.

This illustrated guide covers Docker and Portainer setup, persistent storage, HTTPS certificates, and the Synology reverse proxy.

You can also find Marius Hosting's [Dawarich Docker Compose configuration](https://docker.mariushosting.com/mariushosting/70d5296817f444889b27f1db8c5a1f95).
